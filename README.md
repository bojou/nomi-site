# nomi.house

The public website for Nomi, served by GitHub Pages at https://nomi.house.

- `index.html`: the home page.
- `privacy/index.html`: the privacy policy (Swedish and English). It is the Privacy Policy URL in App Store Connect, so keep it in line with the app's privacy manifest (`Nomi/Nomi/PrivacyInfo.xcprivacy` in the app repository) and update it in the same release whenever the app's data handling changes.
- `CNAME`: the custom domain for GitHub Pages.

Contact: support@nomi.house
